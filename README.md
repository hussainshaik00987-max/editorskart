# Snapja Editor Studio

A responsive editor-focused website with an animated CSS 3D workspace and an eight-step partner profile prototype.

## Local preview

Serve `dist/` using any static HTTP server, for example:

```sh
python -m http.server 5174 --directory dist
```

## Vercel

Import this repository into Vercel. The included `vercel.json` selects the static `dist` output directory. No build or dependencies are needed.

## Prototype scope

Application drafts are stored in browser localStorage. There is no authentication, backend submission, or application review service. Google Fonts supplies the optional web fonts; system fonts are used as fallback.
